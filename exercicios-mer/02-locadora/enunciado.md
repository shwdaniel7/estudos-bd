# Exercício 02 - Locadora

## Uma locadora de veículos faz locações a seus clientes. Para alugar um carro, todo cliente possui um código, nome, cpf, rg, cnh e data de nascimento. O veiculo possui um código, placa, modelo, cor, tipo de combustível, fabricante e quilometragem. A locação possui um código, data de locação, data de entrega, veiculo que foi alugado, código do cliente e valor total.​
